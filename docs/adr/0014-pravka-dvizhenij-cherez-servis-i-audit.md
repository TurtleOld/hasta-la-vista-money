# Движения правятся и удаляются через сервис остатков и аудит, а не аннулируются

ADR-0002 требовал не удалять и не править проведённые движения, а исправлять ошибку компенсирующим движением. Кроме вкладов, это нигде не было реализовано. Для одного пользователя, который исправляет собственные опечатки, полная реализация дорогая (L) и неудобная. «Закрытых периодов», которые ADR защищал, в продукте нет. Поэтому доходы, расходы, чеки, переводы и платежи по кредиту можно править и удалять, но только через `BalanceService.apply_account_deltas` в одной транзакции с аудитом. Проверяемую историю «до → после» хранит аудит, отдельные компенсирующие записи для этого не нужны. Аннулирование с сохранением исходной записи остаётся только у вкладов, где оно уже есть. Одно ограничение сохраняется: движение, к которому привязана строка банковской выписки, нельзя менять так, чтобы строка осталась закрытой без своего движения. У такого движения нельзя менять сумму, счёт и направление. Если его удалить, строка в той же транзакции возвращается в «ожидает решения».
