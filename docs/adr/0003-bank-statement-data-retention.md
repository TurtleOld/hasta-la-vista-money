# Ограниченное хранение банковских выписок

Исходный PDF и чувствительные данные нерешённых строк хранятся 30 дней для сверки вероятных дублей, после чего удаляются. Бессрочно сохраняется только минимальный аудит импорта: hash файла, счёт, даты, итоговые количества и связи с финансовыми движениями; это сохраняет идемпотентность и проверяемость без постоянного хранения банковских документов.
