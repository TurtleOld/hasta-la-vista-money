# Одна семья на инсталляцию, группы разграничивают доступ внутри неё

Приложение self-hosted и рассчитано на одну семью на инсталляцию, поэтому изоляции между независимыми семьями (мультитенантности) нет. Группы остаются для разграничения чтения внутри этой семьи: участник группы читает данные всех участников группы, запись принадлежит только владельцу записи, состав меняется только по приглашению. Многопользовательская изоляция между чужими семьями дороже и в этой модели не нужна, но пользователь без группы или исключённый из неё не должен видеть данные других.
