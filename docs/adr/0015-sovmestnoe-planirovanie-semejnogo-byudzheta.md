# Семейный бюджет планируют и редактируют все участники

ADR-0013 закрепляет запись за владельцем записи. Для **Планов** и **Лимитов** это неудобно: семейный бюджет общий, и планировать его должен каждый участник. Поэтому в области `family` любой участник может задавать и менять план и лимит по категории любого участника. Запись сохраняется от имени владельца категории, чтобы бюджет и «План/Факт» каждого участника оставались в его данных. Лимит без категории сохраняется от имени того, кто его задал. Исключение действует только для планов и лимитов: категории, движения и остальные записи по-прежнему меняет только владелец.
